An original, deterministic chess engine in 4 KB of Python. TINYKNIGHT combines iterative deepening, principal variation search, quiescence, transpositions, selective pruning and tapered evaluation. It tracks repetitions and steers winning endgames toward mate.

Python 3.13, standard library only. The self-contained `main.py` is packed from readable source with the make.fun kit. MIT licensed.
